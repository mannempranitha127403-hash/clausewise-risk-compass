# Clausewise Risk Compass

Design a premium UI for my project called ClauseWise, an AI browser extension that analyzes website Terms & Conditions and Privacy Policies.



Use my uploaded reference screenshot as the visual direction.



DESIGN STYLE:



- A spacious light grey canvas, similar to a spatial note-taking app.

- Floating off-white document cards with rounded corners and subtle shadows.

- Bright lime-green sticky notes.

- A few charcoal-black cards for contrast.

- Minimal typography, generous spacing, and a premium editorial feel.



COLORS:



- Canvas: #DDE3E3

- Lime: #D7FF39

- Paper: #F9F9F5

- Charcoal: #252729

- Text: #202020



MAIN CANVAS:



1. A small ClauseWise logo and website name.

2. A prominent potential risk score from 0 to 100.

3. Five floating cards showing important legal findings.

4. Each finding has a title, severity, and short plain-English summary.

5. Include sticky notes for quick warnings and useful reminders.

6. Include one dark document card and several white paper cards.

7. Add a way to open a detailed view of a finding and inspect its original clause.



IMPORTANT:

Create a visually polished, responsive WEB DESIGN PROTOTYPE first.

Use fictional sample data and label it as demo data.

Do not claim to analyze a real website.

Do not add a backend or AI API yet.

Make the design usable on both mobile and desktop.

Keep the components organized so the interface can later be adapted into a Chrome and Edge browser extension.



Start by generating the interface and let me review it before making additional features.
